## 주요 작업

### 1. 포트폴리오 인트로 스플래시 추가
- 루트 `index.html` 상단에 `portfolio-splash` 마크업을 추가했다.
- `js/splash.js`를 추가해 0~100% 프로그레스, 로딩 바, 완료 후 페이드아웃 흐름을 만들었다.
- `sessionStorage`에 `starbucksPortfolioSplashSeen` 값을 저장해 같은 세션에서 스플래시가 반복 노출되지 않게 했다.
- 스플래시가 열려 있는 동안 `main`과 `skip-links`를 `inert` 처리해 배경 콘텐츠로 포커스가 넘어가지 않도록 했다.
- `prefers-reduced-motion` 환경에서는 애니메이션 부담을 줄이고 빠르게 완료되도록 처리했다.
- `head`의 초기 인라인 스크립트와 `noscript` 스타일을 통해 이미 본 사용자 또는 JS 비활성 환경에서 스플래시가 깜빡이거나 갇히지 않게 했다.

### 2. release/0.2.0 브랜치 생성 후 후속 정리
- `feature/splash-intro`의 스플래시 작업이 `dev`에 병합된 뒤, 해당 상태를 기준으로 `release/0.2.0` 브랜치를 만들었다.
- 이후 작업은 새 기능 추가보다는 릴리스 전 점검 성격에 가깝게 진행했다.
- 링크 정책 불일치, 깨진 회원가입 참조, 공유 메타, 모바일/데스크탑 메뉴 상호작용, planned UI 선명도 같은 릴리스 전 마감 이슈를 정리했다.

### 3. 푸터 소셜 채널과 연락처 동기화
- 루트 `index.html`의 데스크탑/모바일 푸터 소셜 아이콘 4개를 실제 `a` 링크로 변경했다.
- GitHub는 `https://github.com/itb4ng`, Instagram은 `https://www.instagram.com/b4ngs__hwa2`로 연결했다.
- `signup/index.html`도 루트와 동일한 이메일/소셜 링크 기준으로 맞췄다.
- 소셜 아이콘에 hover/focus 스타일을 추가해 링크로 전환된 뒤에도 시각적 피드백이 유지되게 했다.

### 4. 검색 입력 기본 X 중복 제거
- `type="search"` 입력에 브라우저 기본 clear 버튼이 뜨면서 커스텀 `.search__clear` 버튼과 X가 두 개처럼 보이는 문제를 확인했다.
- `::-webkit-search-cancel-button`, `::-webkit-search-decoration`, `::-ms-clear` 등을 숨겨 커스텀 X 버튼 하나만 보이도록 정리했다.
- 루트와 로그인 페이지가 공통 CSS를 쓰기 때문에 두 페이지 모두 같은 기준으로 적용된다.

### 5. 모바일 내비게이션 아코디언 상태 보정
- 모바일 메뉴에서 열린 아코디언에 hover/focus 스타일이 섞여 active 색상이 어색하게 바뀌는 문제를 정리했다.
- 닫힌 메뉴는 `focus-within`만으로 active처럼 보이지 않게 하고, 실제 열린 `.is-open` 상태와 키보드 포커스 표시를 분리했다.
- 모바일 네비가 열린 상태에서는 기존 메뉴가 `focusout`만으로 먼저 접혀 클릭 위치가 밀리는 문제를 막았다.
- 결과적으로 다른 메뉴를 열 때 첫 클릭이 씹히는 느낌을 줄이고, 탭 접근성과 터치/마우스 접근을 분리했다.

### 6. 데스크탑 메뉴 hover/click 우선순위 정리
- 데스크탑에서 메뉴를 클릭해 `.is-open`이 남은 상태로 다른 메뉴에 hover하면 클릭 메뉴와 hover 메뉴 active가 동시에 보이는 문제를 확인했다.
- 마우스 사용자는 hover 전용, 키보드 사용자는 focus/open 전용으로 역할을 분리했다.
- 데스크탑 포인터 클릭에서는 메뉴를 고정하지 않고 기존 open 상태를 닫은 뒤 버튼 포커스를 `blur()` 처리했다.
- 키보드의 `Enter`, `Space`, `ArrowDown` 조작은 기존처럼 메뉴를 열 수 있게 유지했다.

### 7. 회원가입 링크 정책 변경
- 현재 `signup/join.html`이 삭제된 상태이므로 `join.html`을 참조하는 링크를 제거했다.
- `signup/index.html` 로그인 카드의 `회원가입`을 `a`가 아닌 `button`으로 변경했다.
- 루트 리워드 섹션의 `회원가입` CTA도 실제 목적지가 없는 링크 대신 `button`으로 변경했다.
- `data-coming-soon-alert` 속성을 공통 JS에서 처리해 클릭 시 `준비중입니다.` alert을 띄우도록 했다.
- 링크 정책상 실제 이동 목적지가 없는 기능은 링크가 아니라 상태 동작 버튼으로 처리하는 방향을 반영했다.

### 8. CSS 호환성 경고 보정
- `-webkit-line-clamp`만 선언되어 있던 4곳에 표준 `line-clamp: 2`를 함께 추가했다.
- 대상은 `whats-new` 카드 제목/본문, 모바일 프로모션 텍스트, 모바일 공지 텍스트다.
- vendor prefix 경고를 줄이면서 기존 WebKit 기반 말줄임 동작은 유지했다.

### 9. Open Graph / Safari 아이콘 정리
- 기존 `og:image`가 상대경로이고 `og:url`이 실제 배포 주소가 아니라 공유 플랫폼에서 이미지가 누락될 가능성이 있었다.
- Netlify 배포 주소 기준의 절대 URL로 `og:url`, `og:image`, `og:image:secure_url`, `twitter:image`를 정리했다.
- `og:image:width`, `og:image:height`, `og:image:type`, `og:image:alt`를 추가해 Discord 등 공유 크롤러가 이미지를 더 안정적으로 해석하도록 했다.
- `images/common/starbucks_og.png`를 새로 추가했다. 크기는 `1200x630`이다.
- Safari/iOS 홈 화면 아이콘용 `images/common/apple-touch-icon.png`를 새로 추가했다. 크기는 `180x180`이고 배경이 꽉 찬 형태로 만들었다.
- `link rel="apple-touch-icon"`과 `theme-color`를 루트/로그인 페이지에 추가했다.

### 10. 모바일 planned 배지 투명도 조정
- 모바일 전용 플로우의 배지형 planned 항목이 비활성처럼 흐려 보이는 문제를 확인했다.
- `.mobile-flow__item[data-link-status="planned"]`만 `opacity: 1`로 분리했다.
- `mobile-flow__promo-card`, `mobile-flow__more`, `mobile-flow__notice-link` 등 준비중 성격이 강한 UI는 기존 `opacity: .7`을 유지했다.
- `별 적립`, `등급별 혜택`, `My 리워드`, `가까운 매장 찾기`, `리저브 매장`, `드라이브 스루` 같은 정보성 배지는 선명하게 보이도록 조정했다.
