# 2026-04-17 작업 기록

## 개요

오늘은 스타벅스 스타일 정적 퍼블리싱 프로젝트의 접근성 보강과 키보드 UX 정리에 집중했다.

1. `skip link`, `main`, 헤더 메뉴, 히어로 CTA, `order-choice` 다이얼로그까지 실제 사용 흐름 기준으로 접근성 구조를 다시 점검했다.
2. footer와 mobile flow 영역의 링크/제목/수상 내역 구조를 여러 차례 조정하며 탭 흐름과 정보 의미를 함께 맞췄다.
3. 프로모션 슬라이드는 자동 재생을 끄고, 화살표 중심 조작과 활성 슬라이드 CTA 중심 탭 흐름으로 정리했다.

이후 같은 흐름을 다음 작업에서도 이어갈 수 있도록 포커스 설계 원칙 문서와 오늘 작업 기록을 함께 남겼다.

## 주요 작업 상세

### 1. 실제 사용 흐름 기준 접근성 재정리
- 이번 작업의 기준을 “포커스가 보이는 상태”에서 “실제로 불편 없이 사용할 수 있는 상태”로 다시 잡았다.
- `skip link`, 랜드마크, 헤더 메뉴, 히어로 CTA, 다이얼로그, footer까지 한 흐름으로 보고 탭 순서와 포커스 복귀 기준을 점검했다.
- `Tab`은 브라우저 기본 이동을 유지하고, `skip link`, 모바일 메뉴, 다이얼로그처럼 문맥 전환이 생기는 순간에만 포커스를 직접 이동시키는 방향으로 정리했다.

### 2. 헤더 / 모바일 메뉴 / 히어로 상호작용 보강
- 헤더 메인 메뉴는 실제 이동 요소를 `a`, 상태 전환 요소를 `button`으로 나누는 원칙으로 정리했다.
- 한때 메인 메뉴에서 `Tab`을 가로채 하위 메뉴 첫 항목으로 보내는 흐름을 넣었지만, 이후 실무형 기본값에 맞게 제거하고 `Tab`은 기본 흐름으로 되돌렸다.
- 모바일 메뉴는 열릴 때 내부 포커스로 진입하고, 닫을 때는 원래 토글 버튼으로 복귀하는 흐름을 유지하도록 정리했다.
- 히어로 영역은 페이드 애니메이션이 걸린 상태에서도 보이지 않는 요소가 먼저 탭 대상이 되지 않도록 포커스 가능 상태를 보정했다.

### 3. `order-choice` 다이얼로그 사용성 보강
- 다이얼로그가 열릴 때 내부 첫 액션으로 포커스를 이동시키고, 다이얼로그 안에서 `Tab` 순환이 유지되도록 보강했다.
- 닫기 버튼과 `Esc` 동작을 통해 다이얼로그를 빠져나올 수 있게 하고, 닫은 뒤에는 원래 트리거로 포커스를 되돌리도록 맞췄다.
- 배경 영역은 다이얼로그가 열린 동안 비활성화해 키보드 포커스가 뒤 배경으로 새지 않게 정리했다.

### 4. footer / mobile flow 영역의 탭 흐름 재조정
- 사용 요청에 맞춰 `store` 섹션 아래부터 footer 하단, 모바일 플로우 섹션까지 탭 포커스가 이어지도록 링크 구조를 다시 열었다.
- footer 제목은 한때 링크화했지만, 최종적으로는 `h2`만 남기고 하위 메뉴 링크로 진입하는 구조로 되돌렸다.
- 카피라이트는 링크화하지 않고 일반 텍스트로 복원했다.
- 수상 내역은 목적 없는 링크를 제거하고 이미지 목록으로 정리해 탭 흐름에서 제외했다.

### 5. 프로모션 슬라이드 방향 정리
- 프로모션 슬라이드는 실제 항목 수가 2개뿐이어서 자동 재생과 loop가 오히려 키보드 흐름과 인지에 부담이 된다고 판단했다.
- 자동 슬라이드를 끄고, 화살표 버튼은 기존 사용자가 그대로 사용할 수 있게 유지했다.
- 탭 흐름은 “토글 버튼 → 현재 활성 슬라이드 CTA”가 자연스럽도록 맞추고, 비활성 슬라이드 CTA는 탭 순서에서 제외되게 정리했다.
- 이후 필요하면 DOM 순서를 기준으로 “화살표 먼저 / CTA 먼저” 중 어떤 흐름이 더 자연스러운지 추가 조정할 수 있는 상태다.

### 6. 문서화와 작업 메모 정리
- 포커스 이동 원칙과 맥락 복귀 기준을 `docs/focus-flow-guidelines.md`에 별도 문서로 정리했다.
- 헤더부터 다시 읽히는 경우가 언제 자연스럽고, 언제 부자연스러운지 UX 관점 분석도 함께 남겼다.
- 오늘 작업은 날짜 기준 작업 기록 문서로 다시 정리해 이후 수정 판단의 기준점으로 남긴다.

| 프로모션 토글 라벨 문자열 확인 필요 | 콘솔 출력 환경에서 한글 문자열이 깨져 보이는 구간이 있어 실제 파일 상태 점검이 필요 | 동작 우선으로 슬라이드/토글 구조를 정리하고, 다음 점검에서 라벨 문자열과 함수 중복을 한 번 더 정리 예정 |

## 현재 상태

- `skip link`, 헤더 메뉴, 히어로 CTA, 다이얼로그, footer까지 키보드와 스크린리더 흐름 기준으로 큰 구조는 한 번 정리된 상태다.
- 메인 메뉴에서는 `Tab` 기본 흐름을 유지하고, 특수한 문맥 전환에서만 포커스를 이동시키는 방향이 기준으로 잡혔다.
- footer와 mobile flow는 다시 탭 포커스가 이어지도록 복원되었고, 제목/카피라이트/수상 내역의 의미도 최종 방향에 가깝게 정리되었다.
- 프로모션 슬라이드는 자동 재생이 꺼졌고, 활성 슬라이드 CTA 중심으로 탭 흐름을 단순화한 상태다.
- 다만 프로모션 토글 관련 함수 중복과 라벨 문자열은 한 번 더 정리하면 코드 상태가 더 깔끔해질 수 있다.
