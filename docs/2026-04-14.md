## 주요 작업 상세

### 1. First Reserve 섹션 구조 재정리
- 데스크톱은 `style.css`를 기준으로 좌우 균형이 맞는 기본 레이아웃을 먼저 잡았다.
- 중간 폭 구간에서는 `app.css`에서 전체 장면을 같이 줄이는 방식으로 방향을 바꿨다.
- 개별 요소를 따로 옮기는 방식은 간격이 계속 어긋나서, 부모 단위로 보는 방식이 더 안정적이라는 점을 확인했다.
- 버튼 크기는 다른 섹션과 동일한 규격으로 맞추고, 이미지가 버튼을 가리지 않도록 우선순위도 정리했다.

### 2. First Reserve 반응형 보정
- `950px~1279px` 구간은 데스크톱 포스터형을 억지로 미세 보정하기보다, 장면 전체를 같이 축소하는 쪽으로 맞췄다.
- 이 방식은 좌우 간격과 비율을 함께 유지하기 때문에 중간 폭에서 덜 흔들린다.
- 이전처럼 이미지, 제목, 버튼을 각각 따로 조정하는 방식보다 유지보수성이 좋다는 결론을 얻었다.

### 3. 스킵 링크와 메인 메뉴 접근성 정리
- 스킵 링크는 `로그인 바로가기`, `메뉴 바로가기`, `콘텐츠 바로가기` 순서로 추가했다.
- `메뉴 바로가기`는 헤더 첫 메인 메뉴 버튼으로 이동하고, 그 뒤 `Tab`을 누르면 각 섹션의 `h2` 제목부터 읽히도록 흐름을 맞췄다.
- `콘텐츠 바로가기`는 메인 첫 비주얼 섹션으로 이동하도록 연결했다.
- 비주얼 섹션에는 `현재 진행중인 프로모션`이라는 스크린리더용 레이블을 넣어 섹션 의미가 명확하게 전달되도록 했다.

### 4. 메인 메뉴 hover / focus / active 상태 정리
- 메인 메뉴는 hover 시와 focus / active 시 시각 상태가 서로 충돌하지 않도록 정리했다.
- hover는 hover 상황에서만 반응하고, focus / active는 그보다 우선하도록 CSS 우선순위를 맞췄다.
- 서브메뉴는 부드럽게 열리고 닫히도록 transition 기반으로 정리했다.
- 메뉴 항목 사이 간격이 떠 보이던 부분도 시작 위치와 transition 시간을 조정해서 공홈 느낌에 가깝게 다듬었다.

### 5. 문서화
- `First Reserve` 작업 회고는 별도 문서로 정리한 뒤, 오늘 전체 흐름은 날짜 형식의 작업 기록으로 다시 묶었다.
- 다음 작업자가 보면 오늘 어떤 구조 문제를 풀었는지, 접근성 흐름을 어떻게 바꿨는지 바로 파악할 수 있게 정리했다.
