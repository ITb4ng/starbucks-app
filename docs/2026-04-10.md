# 2026-04-10 작업 기록

## 개요

스타벅스 코리아 공식 홈페이지형 퍼블리싱 구조를 유지한 상태에서,  
모바일 흐름 재구성과 `season-drinks` 구간의 대체 섹션 정리에 집중했다.  
특히 모바일에서는 행동 중심 흐름이 먼저 보이도록 `mobile-flow`를 다듬고, 이후 `season-drinks`를 모바일 전용 `What's New` 카드 슬라이드로 교체하면서 카드 노출량, 이미지 비율, 숫자 내비게이션 표현을 반복 보정했다.

## 주요 작업 상세

### 1. 모바일 전용 `mobile-flow` 구조 추가 및 1차 정리
- `season-drinks` 다음에 모바일 전용 래퍼를 추가하고, 기존 데스크탑 구조는 유지한 채 모바일에서만 새로운 흐름이 먼저 보이도록 정리했다.
- 모바일 우선순위를 `REWARDS → STORE → PROMOTION → NOTICE` 순서로 재배치했다.
- 기존 `season-drinks` 이후 ~ `footer` 직전의 기존 섹션은 삭제하지 않고, 모바일에서 `display: none` 처리 가능한 구조로 유지했다.

### 2. `mobile-flow` 2차 보완
- REWARDS 상단 칩은 강한 버튼 느낌 대신 보조 정보 태그처럼 보이도록 톤을 낮췄다.
- STORE는 메인 CTA를 `매장 찾기` 중심으로 두고, `주문 이어가기`는 보조 CTA로 약화했다.
- PROMOTION 카드는 높이와 설명 길이를 줄이고, 모바일 스크롤 피로도가 덜하도록 압축했다.
- NOTICE는 2건 중심의 compact 구조와 `더 보기` 링크 중심으로 단순화했다.

### 3. 기존 `season-drinks` 비활성화 및 모바일 전용 `What's New` 섹션 추가
- 기존 `season-drinks` 마크업은 삭제하지 않고 HTML 주석 처리했다.
- 기존 `season-drinks` 관련 데스크탑/반응형 CSS도 주석 처리해 기존 자산은 남기되 실제 노출에서는 제외했다.
- 같은 위치에 모바일 전용 `whats-new` 섹션을 추가하고, 공홈 WHAT'S NEW 성격의 이벤트/뉴스 소비 방식을 카드 슬라이드 구조로 재구성했다.
- 카드 수는 총 5개로 구성하고, 썸네일은 동일하거나 지정 이미지 자원을 사용하면서 제목/설명은 각각 다른 임시 문구로 작성했다.

### 4. `What's New` Swiper 및 숫자 pagination 적용
- 기존 프로젝트에 포함된 Swiper를 그대로 활용해 `What's New` 전용 슬라이더를 추가했다.
- `autoplay` 없이 사용자가 직접 터치/드래그로 이동하는 구조로 설정했다.
- `loop: true` 기반으로 마지막 카드에서 다시 첫 번째 카드로 자연스럽게 이어지도록 구성했다.
- dot pagination 대신 `1/5`, `2/5` 형태의 숫자 pagination을 적용하고, `realIndex` 기준으로 자연스럽게 갱신되도록 정리했다.

### 5. 카드 이미지 비율 및 노출량 미세 조정
- 2번째 카드와 5번째 카드에는 개별 modifier를 두고 `object-fit: contain`, `object-position` 값을 별도로 적용해 상단 카피가 잘리지 않도록 조정했다.
- `What's New` 슬라이드의 핵심 요구사항인 “다음 카드가 보일랑 말랑 보이는 상태”를 맞추기 위해 `slidesPerView: 'auto'`, `spaceBetween`, 카드 width 값을 여러 차례 보정했다.
- Swiper 기본 CSS가 나중에 적용되면서 `swiper-slide` 폭이 덮이는 문제가 있어, `whats-new .whats-new__slide.swiper-slide`처럼 selector 우선순위를 높여 브레이크포인트별 width 규칙이 안정적으로 적용되도록 정리했다.

## 작업 중 발생한 이슈

| 이슈 | 내용 | 대응 |
| --- | --- | --- |
| Swiper 폭 규칙 충돌 | Swiper 기본 CSS가 뒤에서 `swiper-slide` 폭을 덮어 카드 폭 조정이 일정하지 않게 적용됨 | `What's New` 전용 selector 우선순위를 높여 브레이크포인트별 width 규칙을 고정 |
| 카드 썸네일 상단 텍스트 잘림 | 2번째, 5번째 카드 썸네일에서 상단 카피가 `cover` 크롭으로 잘림 | 카드별 thumb modifier를 두고 `contain + object-position` 방식으로 개별 보정 |
| 카드 노출량 과다/과소 반복 | 다음 카드가 너무 많이 보이거나 거의 안 보이는 상태가 반복됨 | 화면 크기별 slide width 값을 따로 조정하며 “살짝 보이는” 기준으로 반복 미세 조정 |
| Git 상태 확인 제한 | 로컬 저장소 권한 문제로 `git status` 계열 명령 확인이 바로 되지 않음 | 파일 기준으로 수정 범위를 정리하고 문서화는 실제 작업 파일 중심으로 기록 |

## 현재 상태

- 모바일 전용 `mobile-flow`는 최소 구성 방향으로 정리되었고, 기존 데스크탑 공홈형 구조는 유지되고 있다.
- 기존 `season-drinks`는 비활성화된 상태이며, 모바일에서는 `What's New` 카드 슬라이드가 대체 노출되도록 구성되어 있다.
- `What's New`는 숫자 pagination, 무한 loop, 다음 카드 일부 노출 구조까지 반영된 상태다.
- 다만 카드가 보이는 정도는 실제 디바이스 폭에 따라 체감 차이가 있을 수 있어, 실기기 QA 기준으로 마지막 1회 정도 폭 값을 추가 미세 조정할 여지는 남아 있다.
