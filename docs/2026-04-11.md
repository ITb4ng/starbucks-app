## 개요

이번 작업은 전면 리빌드가 아니라, 이미 재배치된 모바일 플로우를 더 명확하고 실제 사용 흐름에 맞게 다듬는 데 초점을 두었다.

## 주요 작업 상세

### 1. Hero 모바일 CTA 및 메시지 정리
- 모바일 Hero 메인 CTA를 `내 주변 매장 찾기`, `앱에서 주문하기` 2개만 남기도록 정리했다.
- 기존 `리저브 매장 찾기`는 Hero에서 제거하고 Store 섹션 보조 액션으로 이동했다.
- Hero 보조 링크는 `이번 시즌 프로모션 보기`로 교체해, 시즌 비주얼과 실제 행동 유도를 자연스럽게 이어주도록 보정했다.
- 모바일 Hero 문구는 시즌 메시지와 사용 행동이 함께 읽히도록 짧고 명확한 톤으로 재작성했다.

### 2. CTA 링크/문구 및 섹션 역할 재정리
- Hero, Rewards, Store, Promotion, Notice 영역의 placeholder CTA를 실제 목적지 기반 링크로 교체하거나 역할이 약한 버튼은 제거했다.
- Rewards는 가입 유도보다 `로그인하고 내 리워드 확인` 흐름으로 문구를 수정했다.
- Promotion은 상단 `전체 보기`를 제거하고 하단 `프로모션 전체보기` 링크로 정리했다.
- Notice는 `공지 전체보기`를 명확한 중단 CTA로 정리하고, 리스트도 실제 공지 경로 중심으로 맞췄다.
- `What's New`는 시즌/브랜드/신규 소식 중심으로 좁히고, Rewards/Promotion/Notice 역할과 겹치지 않도록 카드 문구를 조정했다.

### 3. `What's New` / Promotion 타이포 및 카드 밀도 보정
- `promo-title`과 `whats-new__body h3`는 2줄 클램프는 유지하되, 제목이 붕 떠 보이던 `min-height` 보정 방식은 제거했다.
- 프로모션 카드 제목은 현재 구조에 맞게 세로 정렬 리듬을 다시 맞췄고, 1줄 제목이 불필요하게 떠 보이지 않도록 조정했다.
- `What's New`, `mobile-flow` 관련 섹션의 패딩과 카드 내부 밀도를 소폭 조정해 모바일 스크롤 피로를 줄였다.

### 4. 모바일 헤더 드로어 구조 정리
- 모바일 드로어 첫 화면에 `매장 찾기 / 메뉴 / 로그인` 퀵 링크를 추가해 빠른 이동 우선 구조로 정리했다.
- 데스크톱용 `sub-menu` 리스트는 모바일에서 숨기고, 검색만 퀵 링크 아래에 남기도록 재배치했다.
- `WHAT'S NEW`는 본문 섹션과 역할이 겹치므로 모바일 드로어에서만 숨기도록 처리했다.
- 열린 상위 메뉴는 채워진 배경 대신 왼쪽 그린 포인트와 텍스트/화살표 강조로 바꿔 하위 패널과 시각적으로 분리했다.
- `My 매장`처럼 링크 요소만 색이 달라 보이던 하위 항목은 모바일 드로어 텍스트 스타일과 통일되도록 보정했다.

### 5. 모바일 헤더 스크롤/오버스크롤 안정화
- 모바일 드로어 높이는 `100vh` 고정 대신 실제 viewport 높이를 반영하는 CSS 변수 기반으로 변경했다.
- `-webkit-overflow-scrolling`, `overscroll-behavior`, `touch-action`을 보강해 iPhone 계열 내부 스크롤 끊김을 줄였다.
- 메뉴를 열고 하단까지 이동했을 때 다시 위로 올라오지 않아도 닫을 수 있도록, safe-area 대응 하단 닫기 버튼을 추가했다.
- 하단 닫기 버튼은 항상 노출하지 않고, 스크롤이 최하단 근처에 도달했을 때만 나타나도록 JS로 제어했다.
- 버튼은 가운데 정렬 + 스타벅스/헤더 톤에 맞는 연한 배경과 그린 포인트를 적용했고, 하단에서 올라오는 바텀시트형 모션으로 노출되도록 조정했다.

### 6. 모바일 검색 UX 개선
- 모바일 검색 input은 전 기기에서 `16px`로 고정해 iOS 확대(zoom) 현상을 방지했다.
- 모바일 placeholder는 `통합검색`으로 통일했다.
- 검색창 포커스 시 기존 돋보기 아이콘이 사라지는 위치에 clear `X` 버튼을 추가했다.
- 입력값이 있을 때만 `X`가 나타나고, 탭하면 즉시 비워지도록 했다.
- 기존 UX 흐름은 유지해서, 검색창에서 blur 되면 입력값은 다시 `''`로 초기화되도록 두었다.

### 7. 500px 이하 터치 환경 hover 잔상 제거
- 작은 모바일에서 스크롤 중 `:hover`가 남아 하위 메뉴 텍스트에 밑줄이나 색상 변화가 남는 문제를 별도로 보정했다.
- `500px 이하 + nav-open` 상태에서는 헤더 드로어 안의 `hover` 반응을 기본 상태로 되돌리고, 실제 터치/클릭 계열만 반응하도록 조정했다.
- 상위 메뉴는 현재 열려 있는 항목만 `is-open` 상태에서 강조가 유지되도록 정리했다.

## 현재 상태

- 모바일 Hero, CTA, `What's New`, Rewards/Promotion/Notice 흐름은 실제 행동 유도 기준으로 한 차례 정리된 상태다.
