## 주요 작업 상세

### 1. Hero 섹션 재구성
- 2026 시즌 자산 기준으로 Hero 구조를 재정리했다.
- 데스크탑에서는 시즌 음료 5개를 전시형으로 유지하도록 정리했다.
- `950px 이하` 구간에서는 대표 음료 1개 중심 구조로 전환되도록 수정했다.
- Hero 애니메이션은 기존의 고정 `fade-in` 의존을 줄이고,  
  `data-hero-fade`, `data-fade-desktop-order`, `data-fade-mobile-order` 기반으로 동작하도록 구조를 바꿨다.

### 2. 모바일 Hero CTA 정리
- 모바일 Hero 내부 CTA를 아래 위계로 정리했다.
  - `내 주변 매장 찾기`
  - `앱에서 주문하기`
  - `리저브 매장 찾기`
- 모바일 Hero 카드의 간격, 높이, 라운드, 텍스트 밀도를 조정해 첫 화면 인상을 더 가볍게 다듬었다.
- 헤더와 Hero 상단 연결감이 덜 끊겨 보이도록, 모바일 구간의 헤더 하단 경계와 Hero 상단 배경도 함께 보정했다.

### 3. 시즌 음료 상세 섹션 추가 및 정리
- Hero 아래에 `season-drinks` 섹션을 추가했다.
- 섹션은 **대표 카드 1개 + 일반 카드 4개** 구조로 정리했다.
- 카드 구조는 유지하면서 이미지, 제목, 설명, CTA 리듬을 더 안정적으로 맞췄다.
- 카드 버튼 텍스트를 `주문하러 가기`로 통일했다.
- 카드 CTA가 실제 행동 유도 역할을 하도록 주문 선택 레이어와 연결했다.

### 4. 시즌 음료 이미지 자산 교체
- 시즌 음료 카드 5개 모두 원본 이미지 기준으로 교체했다.
- `picture > source + img` 구조는 유지했다.
- `540px 이하` 구간에서 첫 번째 카드가 더 작은 모바일 자산을 타며 흐려 보이던 문제를 확인했고, 고해상도 원본을 사용하도록 수정했다.
- 카드별 이미지 비율을 유지한 채, 모바일과 데스크탑에서 자연스럽게 축소/확대되도록 비주얼 영역 구조도 함께 조정했다.

### 5. 주문 바텀 시트 / 데스크탑 모달 흐름 복구
- `order-choice` 레이어를 다시 추가했다.
- 모바일에서는 **바텀 시트**, 데스크탑에서는 **중앙 정렬 모달** 패턴으로 같은 정보 구조를 유지하도록 정리했다.
- 스크롤 잠금, dim, ESC 닫기, 포커스 이동 및 복귀 로직을 다시 맞췄다.
- 스크롤 복원 시 위에서 아래로 내려오는 느낌을 줄이기 위해, 복원 시점의 `scroll-behavior` 처리도 반영했다.
- 외부 사이트 직접 이동 시 스타벅스 측 접근 제한 화면이 노출되는 이슈를 확인했고, 주문 CTA의 목적지/문구 재정의가 필요하다는 점도 확인했다.

### 6. CSS 구조 정리
- 공통 규칙은 `common.css`
- 데스크탑 기본형은 `style.css`
- 반응형 및 디바이스 보정은 `app.css`

위 기준으로 파일 역할을 다시 정리했다.

추가로:
- `box-sizing: border-box` 같은 공통 성격의 규칙은 `common.css` 쪽으로 이동했다.
- `app.css` 내부의 일부 중복 선언도 함께 정리했다.
- 모바일 카드의 라운드, 비주얼 박스 반경, 내부 여백 관계도 다시 조정했다.

### 7. JS 정리
- `main.js`에 Hero fade 순서 제어와 주문 선택 레이어 동작을 다시 정리했다.
- 중간에 깨진 문자열과 문법 오류 때문에 동작이 멈추던 구간을 복구했다.
- Hero 애니메이션 순서 제어와 주문 레이어 오픈/닫기 흐름이 현재 구조 기준으로 다시 연결된 상태다.

## 현재 상태

- Hero / 시즌 음료 / 주문 바텀 시트 흐름은 다시 연결된 상태다.
- 시즌 카드 이미지 렌더링은 `540px 이하`와 `540px 초과` 구간에서 추가 미세 조정 여지가 남아 있다.
- 데스크탑에서는 대표 카드 1개 + 일반 카드 4개 구조가 잡혔지만, 일반 카드 비주얼 크기와 텍스트/버튼 리듬은 추가 보정 여지가 있다.
- `app.css`는 여전히 반응형 규칙이 많은 편이라, 추후 한 번 더 블록 단위 정리가 필요하다.
- 주문 CTA는 현재 동작 흐름은 복구되었지만, 외부 링크 연결 정책상 최종 목적지와 문구를 다시 정리할 필요가 있다.
